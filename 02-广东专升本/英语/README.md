# 英语语法四层进阶体系（零基础专用）

## L0 级：识别零件（词性认知）

在搭积木之前，你必须知道手里拿的是什么形状的积木。英语只有 **4 种核心词性** 和 **2 种辅助词性**。

### 四大核心（实词）
- **名词 (n.)**：人或物（如 `apple`, `student`）。是句子的主角。  
- **动词 (v.)**：动作（如 `eat`, `run`）。是句子的心脏。  
- **形容词 (adj.)**：用来修饰名词（如 `beautiful`）。像衣服。  
- **副词 (adv.)**：用来修饰动词或形容词（如 `quickly`, `very`）。像特效。

### 两大辅助（虚词）
- **介词 (prep.)**：表示位置或关系（如 `in`, `on`, `with`）。它不能单独使用，必须和名词绑在一起构成“介词短语”（如 `in the room`）。  
- **连词 (conj.)**：连接词或句子（如 `and`, `but`, `because`）。

> **验收标准**：随便给你一个常用词，你能准确说出它的词性。

## L1 级：搭建主板（五大基本句型）

这是英语语法的绝对核心。任何复杂得像天书一样的长难句，剥去修饰的外衣后，都只有这 5 种骨架。

| 句型 | 逻辑 | 示例 |
|------|------|------|
| **主语 + 谓语**（主谓） | 某人/某物独立完成一个动作。 | `The machine works.`（机器运作。） |
| **主语 + 谓语 + 宾语**（主谓宾） | 某人/某物把动作作用在另一个对象上。 | `I love you.`（我爱你。） |
| **主语 + 系动词 + 表语**（主系表） | 描述主语的状态或特征（最常见的系动词是 am/is/are）。 | `She is beautiful.`（她很漂亮。） |
| **主语 + 谓语 + 间接宾语 + 直接宾语**（主谓双宾） | 给某人某物。 | `He gave me an apple.`（他给了我一个苹果。） |
| **主语 + 谓语 + 宾语 + 宾语补足语**（主谓宾补） | 让宾语变成某种状态。 | `The news made him sad.`（这个消息让他很难过。） |

> **验收标准**：看到一个简单句，能瞬间指出它的主语是谁，谓语是谁。  
> **铁律**：一个英语句子，必须有且只有一个核心谓语动词。

## L2 级：给心脏升级（动词的时态与语态）

在 L1 中我们知道了“动词”是句子的心脏，但在英语里，心脏是会“变形”的。这是专升本单选题最爱考的考点。

### 1. 时态（时间 + 状态）

动词要根据事情发生的时间改变拼写。你不需要学全 16 种时态，专升本只重点考 **5 种**：

- **一般现在时**：经常发生的事（`do` / `does`）。  
- **一般过去时**：过去发生的事（`did` / 动词加 `-ed`）。  
- **一般将来时**：将要发生的事（`will do`）。  
- **现在进行时**：此时此刻正在发生（`am/is/are + doing`）。  
- **现在完成时**：过去发生的动作，对现在造成了影响（`have/has + done`）。

### 2. 语态（被动语态）

- **逻辑**：当主语不是动作的发出者，而是承受者时，必须用被动语态。  
- **公式**：`be 动词 + 过去分词 (done)`。  
- **示例**：`The cup was broken by him.`（杯子被他打破了。）  
- **重点**：专插本考试中，只要物作主语，大概率考被动语态。

## L3 级：无限扩展长难句（三大从句与非谓语）

当你掌握了 L1 和 L2，句子已经能跑通了。L3 就是给句子加装各种“插件”，把简单句拉长，这就是阅读理解的难点。

### 1. 定语从句（给名词加超长修饰）

- **逻辑**：英语里，如果形容词很长（是一个句子），必须放在名词后面。  
- **示例**：`The book (which I bought yesterday) is very expensive.`  
- **拆解法**：看到 `which`, `who`, `that` 引导的从句，直接用括号括起来，它只是个修饰语，把它删掉，句子的主干 `The book is very expensive` 就露出来了。

### 2. 非谓语动词（一山不容二虎）

- **逻辑**：L1 中说过，一个句子只能有一个谓语动词。如果句子里还想出现其他动词，必须把它“降级”成非谓语。  
- **降级规则**：
  - 变成 **to do**：表示目的、将要去做。（例：`I come here to study English.`）  
  - 变成 **doing**：表示主动、伴随进行。  
  - 变成 **done**：表示被动、已经完成。

## 给零基础的“专属语法实战工作流”

对于这四级语法，你每天的专属学习时间（45分钟）应该这样安排：

### 🔹 视频输入（15分钟）
在 B 站搜索“英语兔”或专升本网课。今天只看“名词和动词是什么”，明天只看“主谓宾结构”。看完理解逻辑即可，不要死记硬背。

### 🔹 暴力拆解（30分钟）
1. 拿出一篇专升本历年真题的阅读理解。  
2. 不去管文章的意思，不去查生词。  
3. 只做一件事：**用红笔把每一句话的核心谓语动词找出来**（L1 级测试）。  
4. 如果找对了，把这个动词左边的部分看作主语，右边的部分看作宾语/表语。  
5. 遇到 `in`, `on`, `with` 开头的介词短语，或者 `which`, `that` 引导的从句，全部用括号 `( )` 括起来忽略掉（L3 级降维）。
