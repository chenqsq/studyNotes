# 七、必须掌握的命令

## Git

```bash
git clone
git pull
git add .
git commit -m "提交信息"
git push
```

---

## pnpm

```bash
pnpm install
pnpm dev
pnpm build
```

---

## Maven

```bash
mvn clean
mvn install
mvn spring-boot:run
```

---

## Docker

```bash
docker compose up -d
docker compose down
docker ps
```
